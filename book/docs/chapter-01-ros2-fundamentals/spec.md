# Chapter 1: ROS 2 Fundamentals - Specification

## Purpose

This chapter introduces students to ROS 2 (Robot Operating System 2) fundamentals, providing a foundation for understanding the robotic nervous system that connects AI to physical action.

## Tools & Technologies

- ROS 2 Humble Hawksbill
- rclpy (Python client library)
- URDF basics
- Topics, services, actions
- Launch files
- QoS profiles

## Steps

1. Introduction to ROS 2 architecture
2. Creating ROS 2 packages
3. Understanding topics, services, and actions
4. Publisher/subscriber patterns
5. Service implementation
6. Action servers and clients
7. Launch file configuration
8. Quality of Service (QoS) settings
9. Joint control simulation

## Verification

Students will be able to create a ROS 2 Python package to control a simulated joint.
